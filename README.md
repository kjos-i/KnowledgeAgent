# KnowledgeAgent

Knowledge-graph + hybrid-search agent for research articles.

## Stack

- **LanceDB** — embedded vector + BM25 hybrid search over chunked papers.
- **Neo4j** — citation and author graph (L1: papers + citations, L2: authors).
- **LangGraph** — agent topology.
- **Flet** — desktop GUI.

## Status

Early scaffolding. Project name and structure may change as the solution takes shape.
